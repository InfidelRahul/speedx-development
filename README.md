# SpeedX - High-Performance WordPress SPA Theme

SpeedX is a modern, lightweight WordPress theme built for speed and seamless user experience. It features a Single Page Application (SPA) architecture that eliminates page reloads, providing instant navigation and fluid transitions.

## Features

- 🚀 **SPA Architecture**: Instant page loads with no full-page refreshes
- 🎨 **Neumorphic Design**: Modern soft-UI aesthetic with depth and texture
- 📱 **Fully Responsive**: Optimized mobile hamburger menu and desktop navigation
- 🔍 **Widget-Ready Search**: Reusable search widget for sidebars, headers, or footers
- ⚡ **Performance First**: Minimal JavaScript, vanilla CSS variables, no heavy frameworks
- ♿ **Accessible**: ARIA labels, keyboard navigation, and semantic HTML
- 🛡️ **Secure**: Nonce verification, input sanitization, and security headers

## Installation

1. Upload the `speedx` folder to `/wp-content/themes/`
2. Activate the theme via **Appearance > Themes** in WordPress admin
3. Go to **Appearance > Widgets** to add the "SpeedX Search" widget to your desired areas
4. Configure menu locations under **Appearance > Menus**

## Requirements

- WordPress 5.0 or higher
- PHP 7.4 or higher

## Customization

- **Colors & Typography**: Modify CSS variables in `style.css`
- **Menu Locations**: Primary (desktop/mobile) and Mobile Drawer menus available
- **Widgets**: Sidebar, Footer, and custom widget areas supported
